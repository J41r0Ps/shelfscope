# 📚 ShelfScope — Book Catalogue Scraping & Analysis

> A Data Science pipeline that builds a 1000-book dataset from scratch by scraping a live
> book-catalogue site, then runs a full OSEMN cycle (Obtain → Scrub → Explore → Interpret)
> to uncover patterns in pricing, ratings, stock and category distribution.

**Status**: 🚧 In progress — built for the Data Science course (Thomas More, 2APPAI).

---

## 🎯 Project goal

Most course-level data projects start from a ready-made CSV. ShelfScope instead builds the
**entire dataset from scratch**, then takes it through every stage of the data science lifecycle:

1. **Scrape** 1000 books from [books.toscrape.com](https://books.toscrape.com) in two passes —
   50 paginated listing pages, then all 1000 individual detail pages.
2. **Clean** the raw scraped strings into analysis-ready types using regex and Pandas.
3. **Explore** the dataset with NumPy, Pandas, Matplotlib and Seaborn — distributions,
   correlations, category comparisons, outlier detection.
4. **Interpret** the findings honestly, including what this dataset *cannot* tell us.

---

## 🗂️ Data source

| Source | Type | What it provides |
|---|---|---|
| [books.toscrape.com](https://books.toscrape.com) | Web scraping (requests + BeautifulSoup) | title, price, star rating, availability, category, UPC, description, stock count, review count, tax |

**Why this source**: it's a sandbox site built explicitly for scraping practice, so it's both
sanctioned and stable — this notebook won't silently break when a site redesigns. It also has a
clean mix of numeric and categorical fields, which is what makes meaningful exploration possible.

### Two-pass scraping strategy

| Pass | Pages | Fields obtained |
|---|---|---|
| 1 — listing pages | 50 | title, price, star rating, availability, detail URL |
| 2 — detail pages | 1000 | category, description, UPC, exact stock count, review count, tax breakdown |

The second pass is necessary because **category** — the most useful categorical variable for
analysis — only appears in the breadcrumb on each book's own page, not on the listing cards.

---

## 🧬 Pipeline (OSEMN)

| Stage | Notebook | Output |
|---|---|---|
| **Obtain** | `01_scraping.ipynb` | `data/raw/books_raw.csv` (1000 × 13) |
| **Scrub** | `03_cleaning.ipynb` | `data/processed/books_clean.csv` |
| **Explore / Interpret** | `04_exploration.ipynb` | charts + written findings |

Each notebook saves a checkpoint CSV, so later stages re-run instantly without re-scraping.
The ~20-minute scrape happens once.

## ⚠️ Limitations

- **Prices and ratings on books.toscrape.com are randomly assigned** and carry no real-world
  meaning — the site states this explicitly. Findings describe *patterns within this dataset*,
  not real book-market economics. This is treated as a core caveat throughout the analysis,
  not a footnote.
- Review counts are `0` for every book on the site, making that field analytically empty —
  documented rather than silently dropped.
- One title appears twice in the catalogue (different UPCs and URLs) — genuine site data,
  handled explicitly in the cleaning stage.
